# Creator outreach — DM templates + code scheme

Spanish is dialect-neutral: infinitives, no tú/vos, no possessive "tu",
impersonal "se". Short, peer-to-peer, never "brand voice". The offer is always
the same trade: **a personal Pro code + a guaranteed repost to our audience**, in
exchange for one clip we can repost. That trade is the whole pitch.

## Code scheme

One code per creator, so installs are attributable. Format: `TARIMA-<HANDLE>`
(e.g. `TARIMA-LUCHITA`). Issue via the redeem system (`store/redeem-backend.gs`).
Log every code in `seed-list.csv`. The code does two jobs: gives the creator free
Pro, and tells us who actually drives installs.

## Tier 1 — micro freestylers (1k–50k). 80% of effort.

**First DM (cold):**
> Buenas, sigo lo que subís de freestyle y está muy bueno. Armé una app para
> entrenar improvisación: pone un beat y van apareciendo las palabras al ritmo
> para no perder el flow. ¿Te tiro un código de la versión Pro gratis para
> probarla? Si te sirve y querés grabar una sesión, la reposteamos en nuestra
> cuenta y te etiquetamos.

**Follow-up (if they engage):**
> Genial. Acá va el código: TARIMA-XXXX (se canjea dentro de la app, en Pro).
> Si grabás una sesión de pantalla con el reto que te tira, mandámela y la
> subimos esta semana. Cualquier duda me decís.

**After they post:**
> Subida y etiquetada 🙌 quedó buenísima. Si querés te paso un reto más difícil
> para la próxima.

## Tier 2 — mid (50k–500k): coaches, "aprende a rapear", beat producers.

> Buenas, hago Tarima, una app para entrenar freestyle (beat + palabras al ritmo,
> niveles, diccionario de rimas). Para lo que enseñás puede encajar como
> herramienta. ¿Te paso acceso Pro y armamos juntos un video de niveles con tu
> cara? Vos ponés el flow, nosotros la edición y el reposteo cruzado.

## Tier 3 — known names: only after the format already circulates.

Pitch a one-off, never a "deal", never first. Lead with proof ("ya lo están
usando estos creadores", link reposts). Keep it one line and low-ask.

## Rules of the trade (so it compounds)

- **Repost within 24h or the reward is worthless.** Speed IS the payment.
- Personalise the first line (reference an actual clip of theirs). No copy-paste
  feel.
- Track in `seed-list.csv`: who replied, who posted, whose code drove installs.
  Reallocate to whoever converts. Most won't — that's expected.
- Never buy followers or run paid promo at this stage. Seeding only.
